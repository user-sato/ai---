# LINE AI書記Bot 使い方

このBotは、対象のLINEグループで交わされた会話を記録し、決定事項・やること・未解決事項を整理する書記です。通常の会話へ割り込んで返信することはありません。

## 普段の使い方

特別な書式は不要です。いつものように話してください。決定、依頼、課題、相談を含む会話は、数分後に候補として台帳へ整理されます。

候補はAIが自動で作りますが、**決定事項やタスクとして確定するまで人が確認します**。Botが担当者、期限、金額を推測して確定登録することはありません。

「了解です」などの短い相づちも記録されます。ただし、AI解析の対象にせず、API利用を抑えます。

## LINEコマンド

グループで次のように送ります。

| 送る内容 | 返る内容 |
|---|---|
| `/bot 状態` | Botの受信状態、利用中のAI、記録済み発言数 |
| `/bot 決定事項` | 人が承認して確定した決定事項 |
| `/bot 残課題` | 対応中のタスクと未解決課題 |
| `/bot 確認待ち` | AIが抽出し、人の確認を待つ候補 |
| `/bot 今週` | 最新の週次レポートへのリンク |

候補のIDが表示されたら、管理者は次の操作をします。

```text
/bot 承認 I-xxxxxxxx
/bot 却下 I-xxxxxxxx
```

`I-xxxxxxxx`は`/bot 確認待ち`で表示されるIDです。承認できるのは、導入時に設定された管理者だけです。

## ステータスの意味

| 表示 | 意味 |
|---|---|
| `PENDING` | AIが候補として抽出。まだ確定していない |
| `CONFIRMED` | 管理者が承認した決定事項 |
| `OPEN` | 対応が必要なタスクまたは未解決課題 |
| `REJECTED` | 管理者が却下した候補 |
| `CHANGE`（種別） | 既存の決定と矛盾する可能性があり、確認が必要な変更候補。通常は`PENDING`として表示される |

## 週次レポート

毎週日曜20時頃（日本時間）に、前回の週次締め以降の会話をまとめた週次レポートを作ります。Google Docsへのリンクを対象グループへ投稿します。

GASの時刻トリガーは数分程度前後することがあります。週次レポートには、記録した会話件数と、台帳にある決定・タスク・課題の状況を載せます。

## 困ったとき

- Botが反応しない: `/bot 状態`を送る。反応しなければ、管理者がWebhook設定とApps Scriptの実行履歴を確認する。
- 候補が不正確: `/bot 却下 <ID>`で却下し、必要なら人が正しい内容をグループに書く。AIの候補そのものを確定事項として扱わない。
- すぐに反映されない: 会話の整理は通常5分ごとに行う。数分待ってから`/bot 確認待ち`を送る。
- 他のグループの内容を記録したくない: Botは初期登録した1グループだけを対象にする。他グループや個人トークは記録しない。

## 会話の扱い

対象グループのテキスト発言は、Bot専用のGoogleスプレッドシートに記録されます。決定候補には、根拠となる発言IDと原文引用を紐づけます。画像・ファイル・音声はこのMVPでは内容を解析しません。
