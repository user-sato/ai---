# LINE AI書記Bot 使い方

このBotは、対象のLINEグループで交わされた会話を記録し、決定事項・やること・未解決事項を整理する書記です。通常の会話へ割り込んで返信することはありません。

## 普段の使い方

特別な書式は不要です。いつものように話してください。決定、依頼、課題、相談を含む会話は、数分後に候補として台帳へ整理されます。

候補はAIが自動で作りますが、**決定事項やタスクとして確定するまで人が確認します**。Botが担当者、期限、金額を推測して確定登録することはありません。

「了解です」などの短い相づちも記録されます。ただし、AI解析の対象にせず、API利用を抑えます。

## LINEコマンド

Botを文頭でメンションして、次のように送ります。

| 送る内容 | 返る内容 |
|---|---|
| `状態` | Botの受信状態、利用中のAI、記録済み発言数 |
| `使い方` | この操作説明をLINEで返す |
| `まとめ` | 現在の決定・確認待ち・未解決と主な項目。AI APIは呼ばない |
| `整理して` | 直近12時間の決定・進行方針・残課題と統括提案を作る |
| `3日分整理して` | 指定した日数分を整理する。最大31日 |
| `直近3日分まとめて` | 上と同じ期間整理の言い換え。「7日分の整理」「1週間分まとめて」「７日分整理してください」なども同じ |
| `3日間の流れで次に何をすべき？` | 「N日分」「N日間」「直近N日」「N週間」を含む質問は、その期間を背景に統括回答する |
| 任意の質問 | 直近12時間を背景に統括として回答する |
| `決定事項` | 人が承認して確定した決定事項 |
| `進行方針` | 人が承認し、現在有効な進め方 |
| `残課題` | 対応中のタスクと未解決課題 |
| `確認待ち` | AIが抽出し、人の確認を待つ候補 |
| `今週` | 最新の週次Markdownへのリンク |

候補のIDが表示されたら、管理者は次の操作をします。

```text
@Bot 承認 I-xxxxxxxx
@Bot 却下 I-xxxxxxxx
```

`I-xxxxxxxx`はBotをメンションして`確認待ち`と送ると表示されるIDです。承認できるのは、導入時に設定された管理者だけです。

## ステータスの意味

| 表示 | 意味 |
|---|---|
| `PENDING` | AIが候補として抽出。まだ確定していない |
| `CONFIRMED` | 管理者が承認した決定事項 |
| `ACTIVE` | 管理者が承認した現在の進行方針 |
| `OPEN` | 対応が必要なタスクまたは未解決課題 |
| `REJECTED` | 管理者が却下した候補 |
| `CHANGE`（種別） | 既存の決定と矛盾する可能性があり、確認が必要な変更候補。通常は`PENDING`として表示される |

## 週次レポート

毎週日曜20時頃（日本時間）に、前回の週次締め以降の会話をまとめたMarkdown週次レポートを作ります。「整理」と「統括ならどうするか」を含め、Google Driveファイルへのタイトル付きリンクを対象グループへ投稿します。

LINEのノート投稿はMessaging APIで利用できないため、週次レポートはグループチャットへ届きます。

GASの時刻トリガーは数分程度前後することがあります。週次レポートには、記録した会話件数と、台帳にある決定・タスク・課題の状況を載せます。

新しい会話も継続中の管理事項もない週は、AI APIを呼ばず「新しい動きなし」のMarkdownを作ってリンクを投稿します。

AIを使うメンション依頼はグループ全体で1日20回までです。期間指定は1〜31日、1回にAIへ渡す本文と管理事項は合計60,000文字までです。導入前に取り込んだ過去のやりとりは、`整理して`・`N日分整理して`・任意の質問の対象期間に含めます（例: 導入直後でも`7日分整理して`で過去7日分を整理）。週次レポートには含めません。

整理・統括の返信の先頭には「対象: 期間／発言N件（うち導入前の履歴M件）」が付きます。依頼した期間と違う場合や、件数が想定より少ない場合はこの行で確認できます。「11月4日」のような日付だけの書き方は期間指定として扱いません。

待たずに現在の台帳を確認したい時は、Botをメンションして`まとめ`と送る。これは保存済み項目を即時に一覧化するだけで、会話をAI APIへ追加送信しない。直近の会話は通常5分ごとの整理後に反映される。

## 困ったとき

- Botが反応しない: Botをメンションして`状態`を送る。反応しなければ、管理者がWebhook設定とApps Scriptの実行履歴を確認する。
- 候補が不正確: Botをメンションして`却下 <ID>`で却下し、必要なら人が正しい内容をグループに書く。AIの候補そのものを確定事項として扱わない。
- すぐに反映されない: 会話の整理は通常5分ごとに行う。数分待ってからBotをメンションして`確認待ち`を送る。
- 他のグループの内容を記録したくない: Botは初期登録した1グループだけを対象にする。他グループや個人トークは記録しない。

## 会話の扱い

対象グループのテキスト発言は、Bot専用のGoogleスプレッドシートに記録されます。決定候補には、根拠となる発言IDと原文引用を紐づけます。画像・ファイル・音声はこのMVPでは内容を解析しません。
