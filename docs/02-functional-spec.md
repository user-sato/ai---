# 02 機能・運用仕様

## 機能一覧
| ID | 機能 | MVP | 説明 |
|---|---|---|---|
| F01 | LINEテキスト受信 | 必須 | Webhookでグループ発言を保存 |
| F02 | AI抽出 | 必須 | 決定候補、進行方針候補、タスク候補、課題、変更候補を抽出 |
| F03 | 確認・修正 | 必須 | Botを文頭メンションして`確認待ち`、`承認 <ID>`、`却下 <ID>` |
| F04 | 状況照会・統括 | 必須 | `残課題`、`決定事項`、`進行方針`、`今週`、期間整理、任意相談 |
| F05 | Drive同期 | 必須 | 現況書、Sheets、週次・日次Markdownの作成・更新 |
| F06 | 週次自動報告 | 必須 | 日曜20時、LINEへ要約とリンク |
| F07 | 月別フォルダ作成 | 必須 | 月替わり時に新規作成、遅延到着にも対応 |
| F08 | 月次まとめ | 推奨 | 月末集計、翌月に前月分Docs作成 |
| F09 | 自発的な議論介入 | 対象外 | Botは議論へ積極参加しない |
| F10 | Google側編集の逆同期 | 対象外 | 一方向同期のみ |

## 抽出ルール
- 「〜したい」「〜はどう？」は提案。合意の明示がなければ決定ではない。
- 「担当する」「日曜までに」の発言は候補タスク。発言者と対象者の同定が曖昧なら担当未確定。
- 日付はAsia/Tokyoで解釈し、元発言日時と解釈結果を保持。
- AI推定で担当者、期限、金額を埋めない。
- 確定済み決定と食い違う場合は矛盾候補を起票し、勝手に上書きしない。
- AIが作った決定候補は承認までPENDING。承認されたものだけCONFIRMED。

## 出力文書
- **現況書**：プロジェクト全体の現在地。確定事項、確認待ち、タスク、課題、最終更新日時。
- **週次Markdown**：対象期間、整理、決定事項、進行方針、残課題、統括提案、根拠。
- **月次まとめ**：月全体の動き、主要決定、未解決課題、翌月持越し、週次レポートへのリンク。
- **タスク管理表**：Tasks、Issues、Decisions、SyncStatusの各シート。

## レポートの品質条件
- LINEで話されていない進捗を推測しない。「進捗不明」と「遅延」を区別。
- 決定・提案・保留・撤回を混同しない。
- 出典メッセージIDと日時を保持。LINEメッセージへの直接リンクは取得可能性を確認してから表示。
- レポートの期間は前回の日曜20:00 JST〜当週日曜20:00 JST（終端排他）。
