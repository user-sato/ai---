# 04 Google Drive出力

## 現行フォルダ構成

```text
Bot専用Driveフォルダ/
├── 00_プロジェクト現況書                 [Google Docs / 常設]
└── YYYY/
    └── YYYY-MM/
        ├── 日次レポート/
        │   └── YYYY-MM-DD_HHmm_<種類>_<依頼ID>.md
        └── 週次レポート/
            └── YYYY-MM-DD_週次レポート.md
```

スプレッドシートは正本として別途1ファイルを用意し、運用者がBot専用フォルダ内へ配置する。GASは既存スプレッドシートを移動しない。

## 作成規則

1. 年・月・用途フォルダは必要になった時点で作成する。月初専用ジョブは使わない。
2. `整理して`、期間整理、任意の統括相談は`日次レポート`へMarkdownを作る。
3. 日曜20時頃JSTの週次は`週次レポート`へMarkdownを作る。
4. 同じ依頼ID・週次締切では同名ファイルを再利用し、再試行による重複を防ぐ。
5. 日次・週次Markdownは既存ファイルを削除・内容上書きせず、生成前に同名ファイルを検索する。
6. 常設の現況書は最新の`Items`から文書全体を更新するため、手動編集は次回同期で失われる可能性がある。

## 共有権限

Botはファイルを自動公開しない。LINEグループ参加者がURLを開けるよう、運用者がBot専用親フォルダを必要なGoogleアカウントへ共有する。LINEの参加者とGoogleの閲覧権限は自動では一致しない。

月次まとめは現行MVPでは生成しない。
