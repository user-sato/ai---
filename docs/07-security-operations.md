# 07 セキュリティ・運用

## 導入前の必須事項
1. グループ参加者へ、発言を外部保存しAI解析すること、保存先、閲覧者、保存期間を説明し、合意を得る。
2. Google Docs/Sheetsの共有範囲を決定。LINEのグループ参加者とGoogle閲覧権限は自動一致しない。
3. LINEチャネルシークレット、アクセストークン、Google OAuth資格情報、OpenAI APIキーはSecret Manager等に保管。
4. ログにメッセージ全文や認証情報を原則出さない。
5. LINE署名検証、Webhook再送、リトライ、レート制限、DBバックアップを実装。
6. データ削除要求、Bot退会、グループ閉鎖時の消去手順を設計。

## 送信取消・個人情報
- LINE側で送信取消されたメッセージが、BotのDB・生成Docsから必ず自動削除されるとは限らない。削除受付コマンドまたは管理者手続きを用意。
- 個人名の推定・発言者の同一視を慎重に扱う。担当者をAI推測で確定しない。
- テキストのみMVP対象。画像、音声、添付ファイルは保存・解析対象外。

## 可観測性
- Webhook受信件数、解析待ち件数、同期成功率、週次レポート成功率、LINE通知成功率、API利用額を監視。
- Google認可切れやAPI失敗は管理者に通知。再試行後も失敗なら手動復旧。
- AIモデル名、プロンプト版、解析対象期間、結果の根拠を監査可能にする。

## 費用
クラウド・DB・AI・LINE送信通数・Google API利用制限を実装前に試算。過去に挙げた月額1,000〜3,000円は確定見積もりではない。Cloud SQLは固定費が生じ得るため、小規模運用ではDBサービス代替も比較する。
