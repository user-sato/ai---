# 09 未決事項・暫定実装方針

## ユーザーが決定した要件
- LINEグループのAI書記・管理Bot（積極的な議論介入はしない）。
- Google Drive（DocsとSheets）を人間向けの保存先にする。
- プロジェクトごとに**毎月フォルダを自動作成**する。
- 定期的に自動で会話をまとめ、週次レポートと詳細リンクをLINEに投稿する。
- Codexに渡せる分割Markdown資料を用意する。

## 実装を止めないための暫定値（未承認）
| 項目 | 暫定値 | 留意点 |
|---|---|---|
| 週次通知 | 日曜20:00 JST | ユーザーの前回案に合わせる。**速報版**であり、月曜00:00までの完全な週次ではない |
| 集計期間 | 前回週次のcutoff_at（初回は当週月曜00:00）〜今回日曜20:00、終端排他 | **連続したcutoffで欠落・重複を防ぐ**。前回日曜20時以降も次回集計に含める |
| 月次集計 | 暦月00:00〜翌月00:00 JST | 週次と境界が違うことを明記 |
| 月次作成 | 翌月1日09:00 JST、Drive保存のみ | LINE通知なし |
| 解析頻度 | 5分ごと、会話なしはスキップ | AIコスト制御 |
| Drive認証 | 管理者のGoogle OAuth | 対象フォルダの権限付与が必要 |
| Google編集 | Botの生成物を人が直接編集してもDBに反映しない | 原則Bot経由で修正 |
| 承認権限 | 管理者として設定されたLINE userIdのみ | 実IDは環境設定で指定 |
| 保存期間 | 未確定 | 実運用開始前に必ず決定 |
| 課金上限 | 未確定 | 実運用開始前に必ず決定 |
| 対応範囲 | 1グループ・テキストのみ | 複数グループ・添付は将来 |

## 注意が必要な設計上の差分
- `docs/02-functional-spec.md` は一般的な週次期間（月曜00:00〜翌月曜00:00）を記載しているが、日曜20:00に配信する場合は未完了の週となる。MVPは上記の**連続cutoff方式**を優先し、レポートに実際の集計開始・締切を明記する。
- LINEに投稿したテキストとGoogle Docsの共有権限は別管理。リンクを知っているだけでは閲覧できない可能性がある。公開リンクへの自動変更は禁止。
- LINEメッセージの送信取消を検知しても、既に作成したDocsや要約からの完全消去は保証できない。削除手順を別途設計する。
- 本番デプロイ、Google OAuth同意、LINEチャネル設定、OpenAI APIキーの発行は人間の操作が必要。
